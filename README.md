# Garden of Eden SC Sung

Personal website of Eden SC Sung: work (automotive connector and cable assembly sales) and life (reading notes and photography).

Plain HTML, CSS and JavaScript; no build step. Open `index.html` locally, or serve the folder with any static host (GitHub Pages, Netlify, Cloudflare Pages).

- `index.html`: homepage (dark/light split)
- `work.html`: why, how, what, specs, now, contact
- `life.html`: reading notes and photo exhibits
- `assets/js/`: ribbon animation, page logic and a small runtime
- `images/`: web-optimized photos (WebP)
